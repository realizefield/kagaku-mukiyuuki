# kagaku-mukiyuuki

江原予備校 GAMBA 化学シリーズ――無機化学・有機化学の教材リポジトリ。

以前の無機化学専用フォルダ（mukikagaku_*.html 一式）とは別に、無機化学・有機化学の両方を扱う教材をここで管理します。

## 方針

- 大学入学共通テストレベルに対応した内容
- GAMBA化学の共通デザイン（CSS変数・タブ切替・小テスト／練習問題／確認問題などのインタラクティブ要素）を踏襲
- 不登校経験者・中退・通信制高校・社会人・ひとり親家庭等、学習に恵まれない生徒さんにも取り組みやすい教材を目指す

## 構成（予定）

今後、単元ごとのHTML教材をこのリポジトリに追加していきます。
